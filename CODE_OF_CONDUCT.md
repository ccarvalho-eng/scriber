# Code of conduct

Scriber contributors must help maintain a respectful, harassment-free community.

Be constructive, assume good faith, respect differing experiences, and focus criticism on the work. Harassment, discrimination, threats, deliberate disruption, and publication of another person's private information are unacceptable.

Project maintainers may edit or remove contributions and restrict participation when behavior is inappropriate. Report conduct concerns privately through the repository owner's GitHub profile. Reports will be reviewed fairly and kept confidential to the extent practical.
